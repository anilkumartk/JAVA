The principle states that we must use abstraction(abstract classes and interfaces) instead of concrete
implementations. High-level modules should not depend on the low-level module but both should depend on
abstraction.


Eg:
1. In shopping mall we can make payments through credit and debit cards.
2. But If we create instance separately then they depend on them and violates the principle.
3. Instead we can create parent class then these cards extends from the parent card class.
