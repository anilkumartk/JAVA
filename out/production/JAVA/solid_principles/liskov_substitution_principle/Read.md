It applies to inheritance in such a way that the derived classes must be completely substitutable 
for their base classes. In other words, if class A is subtype of class B, then we should be able to 
replace B with A without interrupting the behaviour of the program.

Eg:
1. Facebook Supports all features of SocialMedia Parent Class.So It can replace Parent Class.
2. But Instagram, Whatapp doesn't support all features. So they can't replace it.
3. So we created solution package and implements each interface separately.
