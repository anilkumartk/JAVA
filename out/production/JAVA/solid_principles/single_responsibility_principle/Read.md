The single responsibility principle states that every class / java class must perform single functionality.
Implementation of multiple functionalities in single class can mass up the code.


Eg:
1. In BankService Class all methods / all business logic is writen. If we want change anything then the code
 becomes mass up. It violates single responsibility principle.
2. So we created separate class for each logic. If we want to change or add new feature then we will only
 change that logic or that class. It follows single responsibility principle.
